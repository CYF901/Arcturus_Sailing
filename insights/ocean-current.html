Ocean Current

Ocean current data, analysis, and route planning implications for SE Asia passages.

Major Currents in Our Region

  • Kuroshio (Black River): Flows north through Philippines → Taiwan → Japan. 1-3kts. Strongest in summer.
  • South China Sea Current: Seasonal — clockwise in winter, counter-clockwise in summer.
  • Monsoon currents: Affected by NE/SW monsoon seasons.

Current Data Sources

  • OSCAR Ocean Currents — oscar.noaa.gov (free)
  • Windy — wind/current overlaid maps
  • NOAA WCISA — surface current predictions

Practical Use

For HK → Taiwan: Cross Kuroshio when heading NE. The current can add 1-2kts SOG if you catch it right, or cost you the same if you fight against it.
